## Embedding / 规则候选说明

- 运行时**不**对 16 条底限做 per-clause 向量检索，也未保留向量库依赖。
- `规则候选Agent` = 词法门控 `applicable_rule_ids` + 业务类型过滤。
- 确定性规则全量覆盖条款；LLM 语义研判窗口动态上限（16–32）。
- 系统设置仅配置主模型与本地脱敏模型。

## 导出模式

| mode | 含义 |
| --- | --- |
| `revised` | 可签约修订建议稿（需信审有效、无 CREDIT 阻断、例外审批完成；仅含已采纳风险） |
| `plain` | 原合同副本 / 无批注 |
| `bilingual` | 原文条款后插入指定语言译文（需先完成该语言翻译） |
