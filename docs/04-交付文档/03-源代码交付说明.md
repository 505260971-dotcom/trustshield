# 源代码交付说明

> 项目：信盾 TrustShield ｜ 交付方式：Git 仓库完整源码 ｜ 更新日期：2026-08-03

## 1. 交付内容

本仓库根目录即为可运行源码，无需从文档目录复制代码。源码由前端、后端、演示材料和交付文档组成：

```text
contractguard/
├─ backend/                     # FastAPI 服务、业务规则、Agent 编排、回归脚本
│  ├─ app/
│  │  ├─ graph/                 # 合同审查与信审流程编排
│  │  ├─ services/              # 解析、脱敏、规则、检索、翻译、导出、集成
│  │  ├─ main.py                # REST API 入口与案件工作流
│  │  ├─ auth.py                # 登录、权限与系统配置接口
│  │  ├─ config.py              # 启动安全参数与运行配置读取
│  │  └─ store.py               # SQLite 加密持久化与审计
│  ├─ scripts/                  # 可独立执行的回归/验收脚本
│  ├─ requirements.txt          # Python 依赖
│  └─ .env.example              # 启动级安全参数模板
├─ frontend/                    # React + TypeScript + Vite 前端
│  ├─ src/pages/                # 信审、合同、审批、工作台和治理页面
│  ├─ src/components/           # 可复用报告、工作流与翻译组件
│  └─ package.json              # 前端依赖和构建命令
├─ docs/                        # 产品、接口、演示与本交付文档
└─ dev.py                       # 开发环境一键启动脚本
```

## 2. 关键模块与可追溯位置

| 交付能力 | 主要源码位置 | 说明 |
| --- | --- | --- |
| 信审 ReAct Agent | `backend/app/services/credit_react_agent.py` | 受控证据检索、Claim 核验、多轮执行与失败关闭 |
| 信审工作流 | `backend/app/graph/credit_graph.py`、`backend/app/main.py` | 评估启动、状态推送、人工复核及审批流转 |
| 合同审查工作流 | `backend/app/graph/review_graph.py` | 文件审查编排、条款风险汇总与进度事件 |
| 信审—合同强绑定 | `backend/app/services/credit.py`、`backend/app/store.py` | 生效版本绑定、额度/账期等 `CREDIT_*` 门禁 |
| 确定性规则 | `backend/app/services/deterministic_rules.py` | 封闭底线条款的可解释代码裁决 |
| 脱敏与恢复 | `backend/app/services/mask.py`、`backend/app/services/smart_mask.py` | 本地规则脱敏、任务级映射、智能补足与可逆恢复 |
| 翻译隐私门禁 | `backend/app/services/translate.py` | 无脱敏映射时拒绝外发 |
| 身份与权限 | `backend/app/auth.py`、`backend/app/services/security.py` | JWT、角色权限、管理员设置与连通性测试 |
| 前端工作台 | `frontend/src/pages/` | 角色待办、信审、案件、合同报告、审批和系统管理 |

## 3. 构建与回归入口

```powershell
# 前端构建与静态检查
cd frontend
npm install
npm run build
npm run lint

# 后端关键回归
cd ..\backend
python -m pip install -r requirements.txt
python scripts/test_mask_fast_path.py
python scripts/test_credit_contract_guard.py
python scripts/test_credit_react_agent.py
python scripts/test_translation_privacy.py
```

更多测试按模块放置于 `backend/scripts/`，包括文档解析、合同流程、信审审批、规则目录、用户权限与安全工作流。具体运行说明见 [部署说明](./04-部署说明.md) 与根目录 README 的“验证与测试”。

## 4. 不随源码交付的运行期数据

下列目录或文件已通过 `.gitignore` 排除，避免将敏感信息上传到代码仓库：

- `backend/.env`：令牌签名密钥、Fernet 密钥和初始管理员凭证；
- `backend/data/`：SQLite 数据库、模型运行配置、上传文件、解析资产和导出文件；
- `runtime/`：本地演示运行期文件；
- `frontend/node_modules/`、`frontend/dist/`：可由依赖安装和构建命令重新生成。

交付方应从 `backend/.env.example` 创建新环境配置，并在部署环境完成管理员初始化与模型服务配置。不得将真实账号、密钥、原始合同或财报提交到 Git。

## 5. 建议的归档方式

当前仓库已包含源码和全部交付文档。若需提交离线压缩包，可在确认当前 Git 提交后执行：

```powershell
git archive --format=zip --output trustshield-source-delivery.zip HEAD
```

该命令会从当前提交生成可复现源码包，不会包含被 `.gitignore` 排除的本地密钥、数据库与运行数据。
