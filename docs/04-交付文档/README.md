## 交付使用顺序

1. 阅读方案设计，了解“信审边界先行、合同自动门控”的业务闭环；
2. 按效果验证报告复现脱敏与核心流程回归；
3. 依部署说明启动系统；
4. 使用 `docs/03-演示与交付/模拟测试材料-v2-启明智造场景/` 完成端到端现场演示。

## 交付边界

- 仓库中的启明智造材料均为虚构、脱敏的演练数据，不构成授信、法律或财务意见；
- `backend/.env`、`backend/data/`、`runtime/` 不纳入源码交付，避免携带密钥、运行数据库、上传原文和导出文件；
- 模型地址、模型名和 API Key 为部署侧运行配置，不写入本文档或 Git 仓库。生产环境应按企业网络与数据治理要求配置本地或内网模型服务。
