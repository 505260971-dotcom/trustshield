# 启明智造场景：条款补件与例外说明

## 1. 这份材料怎么用

本文件用于帮助审核专员在首版风险合同进入案件后判断：

- 哪些问题属于客户信审边界，必须回到信审流程；
- 哪些问题属于合同底线，可以直接修订或发起合同例外审批；
- 哪些问题需要业务补充质量、订单、项目背景或书面承诺材料。

## 2. 信审阻断：合同端不可覆盖

| 规则 | 首版合同事实 | 本场景处理 |
| --- | --- | --- |
| `CREDIT_TERM` | 交付后 120 天付款，超过 V1 的 60 天上限 | 将合同修改为交付后 60 天内结清；如果业务确需放宽，必须新建信审 V2。 |
| `CREDIT_PREPAYMENT` | 交付前仅收 25%，低于 V1 的 40%下限 | 修订为至少 60%，不在合同审批中豁免。 |
| `CREDIT_PAYMENT_METHOD` | 允许银行承兑汇票/商业承兑汇票 | 改为银行转账；如要允许承兑，必须更新信审并重新审批。 |
| `CREDIT_DELIVERY_MODE` | VMI/JIT 和供应商管理库存 | 删除 VMI/JIT；若业务必须采用，应更新信审并重新复审合同。 |
| `CREDIT_EXPOSURE` | 合同 CNY 1,200,000 + 既有敞口 CNY 800,000 = CNY 2,000,000 | 将修订合同金额控制在 CNY 1,000,000，合计 CNY 1,800,000。 |

以上问题不能通过“忽略风险”“主管批准可签约”或“集团财务总监例外审批”绕过。它们属于客户级商业条件，不是普通合同条款例外。

## 3. 合同底线风险：可以修订或按权限审批

| 规则 | 首版合同中的问题 | 修订方向 |
| --- | --- | --- |
| R01 | 交付前仅 25% 收款 | 修订为 60% 交付前收款。 |
| R02 | 模塑一体项目交付后 120 天付款 | 修订为 60 天内付款。 |
| R03 | 银行承兑汇票/商业承兑汇票 | 本演练直接删除并统一为银行转账。 |
| R04 | 乙方及关联主体承担连带责任 | 删除连带责任和关联主体外溢。 |
| R05 | 独家供应、排他安排 | 删除排他性和独家性承诺。 |
| R06 | 甲方可无责任取消或调整订单 | 改为提前书面通知，并补偿乙方已经发生且不可转移的成本。 |
| R07/R08 | 质保只有期限；替代品重新起算 | 改为“交付后24个月或300,000啤次，以先到者为准”，替代品不重新起算。 |
| R09 | 乙方承担全部销售国法律识别义务 | 改为由需求提出方提供并确认销售国的适用要求，双方各自承担自身合规义务。 |
| R10 | 违约与赔偿责任上限为合同金额80% | 将可证明的直接损失和违约责任合计控制在合同金额50%以内。 |
| R11 | 合同有效期七年 | 改为三年，续期需双方书面确认。 |
| R12 | 乙方承担间接、附带和预期利益损失 | 将责任限定为可证明的直接损失。 |
| R13 | 责任外溢至甲方、乙方关联企业 | 明确合同只约束签约双方。 |
| R14 | 全部知识产权归甲方 | 改为各方既有知识产权归各自所有，履约仅授予有限、非独占、不可转让许可。 |
| R15 | 未达成调价共识仍按原价供货六个月 | 改为原价持续供货不超过三个月。 |
| R16 | VMI/JIT 交付 | 本演练删除该模式；保留必须走主管审批和新的信审版本。 |

## 4. 可选补件：质量和项目交付说明

如果审核专员希望演示“待补材料”而不是直接修订，可以要求业务补充以下材料：

**补件名称：** 模具验收、质保与替换件规范（模拟）

**补件内容：**

> 本项目模具及试制件的质保期为每批货物交付并验收合格之日起24个月或累计300,000啤次，以先到者为准。替代品或换货件不重新起算质保期，除非双方就新增缺陷另行书面确认。验收标准以双方确认的图纸、样件、检验规范和项目节点记录为准。

**预期动作：**

1. 在案件中创建或保留“待补材料”；
2. 业务上传补件或在合同修订中写入完整条款；
3. 重新审查 V2；
4. 确认补件已关闭后，才继续签约门禁。

## 5. 关键禁止事项

1. 不得以合同例外审批覆盖 `CREDIT_TERM`、`CREDIT_PREPAYMENT`、`CREDIT_PAYMENT_METHOD`、`CREDIT_DELIVERY_MODE`、`CREDIT_EXPOSURE` 或 `CREDIT_OVERDUE_LOCK`。
2. 不得只把报告中的 `CREDIT_*` 发现标记成“已忽略”后导出修订建议稿。
3. 不得在 V1 仍有效时把合同改成比 V1 更长账期、更低预付款、更高金额或新增 VMI/JIT。
4. 如商业上确实需要放宽条件，应新建信审 V2，重新上传和核验财报、敞口，完成主管/终审后再复审合同。
