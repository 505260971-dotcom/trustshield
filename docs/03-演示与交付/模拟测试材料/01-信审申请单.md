## 3. 申请理由

## 4. 审核专员确认/修订依据（如需要手工报送）

量化 Agent 需要在生产环境中以来源证据形成可核验 Claims；如果 Agent 未配置、解析失败或建议额度与本演练边界不一致，审核专员可在系统中选择人工确认/修订，并输入如下说明：

> 已核验 `02-客户财务报告-模拟.docx` 中收入、流动资产、流动负债、资产总额、负债总额、净利润及经营现金流，数据口径均为 2025 年度 CNY。CRM/ERP 快照显示既有敞口 CNY 300,000、逾期 0 天。为控制首批年度供货风险，报送总敞口 CNY 1,000,000、最长账期 45 天、交付前最低收款 30%、仅银行转账且不允许 VMI/JIT。该商业边界严于或不宽于本次演练申请，不涉及未核准的汇率换算。
