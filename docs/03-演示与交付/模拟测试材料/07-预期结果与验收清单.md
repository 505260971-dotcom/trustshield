## 二、风险合同首次审查

`04-风险合同-待审.docx` 金额为 CNY 800,000。既有敞口为 CNY 300,000，因此合同后总敞口为 CNY 1,100,000，超过 CNY 1,000,000 信审上限。

### 必验的信审阻断项

| 规则 | 合同中的触发事实 | 预期结论 |
| --- | --- | --- |
| `CREDIT_TERM` | 交付后 60 天付款 | 60 天 > 45 天，不得合同侧豁免。 |
| `CREDIT_PREPAYMENT` | 合同价款 20% 作为预付款 | 20% < 30%，不得合同侧豁免。 |
| `CREDIT_PAYMENT_METHOD` | 银行承兑汇票 | 生效信审仅允许银行转账。 |
| `CREDIT_DELIVERY_MODE` | VMI 模式 | 生效信审不允许 VMI/JIT。 |
| `CREDIT_EXPOSURE` | 800,000 + 既有 300,000 | 总敞口 1,100,000 > 1,000,000。 |

这些发现的总体级别应为“信审阻断”。对任一 `CREDIT_*` 发现尝试“忽略”时，系统应拒绝；修订建议稿/双语稿也不应允许导出。

### 合同底线的建议观察项

风险合同还故意包含以下典型信号。确定性规则会优先稳定命中 R02/R06/R11/R12/R16；其余项目由规则候选与语义研判、人工复核共同确认。

| 规则 | 风险合同中的信号 | 处理建议 |
| --- | --- | --- |
| R02 | 交付后 120 天结清 | 修改为交付后 45 天内银行转账结清。 |
| R03 | 银行承兑汇票 | 删除，改银行转账。 |
| R04 | 连带责任 | 删除。 |
| R05 | 独家供应/排他 | 删除。 |
| R06 | 客户可无责任取消订单 | 改为补偿不可转移的原料、生产、物流成本。 |
| R07/R08 | 只写 36 个月质保、替代品重新起算 | 改为“24 个月或 300,000 啤次先到者为准”，替代品不重新起算。 |
| R09 | 我方识别销售国全部法律法规 | 改为由需求提出方提供并确认。 |
| R10 | 违约金与损失赔偿合计 80% | 改为不超过合同金额 50%。 |
| R11 | 有效期 7 年 | 改为 3 年。 |
| R12 | 我方承担客户间接损失 | 明确不承担间接、附带、惩罚性或预期利益损失。 |
| R13 | 约束我方全部关联公司 | 改为仅约束签约双方。 |
| R14 | 全部知识产权归客户 | 改为各方既有知识产权归各自所有，有限期且不可转让许可。 |
| R15 | 不得提价，未达一致仍按原价持续供货 6 个月 | 改为持续供货不超过 3 个月。 |
| R16 | VMI 模式 | 删除 VMI；如保留还须主管审批和新的信审版本。 |

## 三、修订合同复审与导出

| 检查点 | 预期结果 |
| --- | --- |
| 上传 `06-修订后合同-复审.docx` | 合同相对方与绑定客户一致；合同金额 600,000 加既有敞口 300,000 = 900,000。 |
| 信审边界 | 45 天、30% 预付款、银行转账、非 VMI/JIT，因此不应有 `CREDIT_*`。 |
| 合同底线 | 文本已按 16 条底线修订；如 AI 仍给出“待确认”，应基于证据核对后关闭或修订。 |
| 导出 | 在没有 `CREDIT_*`、必要审批均完成且采纳修改建议后，允许导出修订建议稿；原文版可用于留档。 |
| 版本控制 | 若信审 V2 后续生效，V1 绑定的合同应提示不是当前已生效信审版本，须用 V2 重新复审。 |
