# 合同评审演示脚本（约 5 分钟）

## 0:00–0:30 登录与工作台

使用管理员账号登录，展示“我的待办、待领取案件、48 小时内到期、阻断级结论”四个团队指标。

## 0:30–1:00 信审前置 + CRM 端口（可选 20s）

进入「客户信审」，点「CRM 对接端口」模拟推送客户并生成草稿；或直接使用已生效版本。强调：**测算模型可独立演进，合同只消费已生效边界**。

## 1:00–1:40 发起案件

进入“发起合同评审”，上传销售合同样本（可再加一份附件），指定信用审核专员，选择“高”优先级，绑定已生效信审版本。提交后停留在实时审查链路。

## 1:40–2:30 AI 审查

展示文档解析、本地脱敏、字段抽取、**规则候选（词法门控，非空向量噱头）**、语义研判、规则引擎和汇总结论。强调：

- 风险项带条款定位、证据、底限原文和修改建议
- 确定性规则全量覆盖；语义窗口动态
- 若有信审越界，总体结论为信审阻断

## 2:30–3:20 原文标注与团队案件

打开报告默认「原文风险标注」双栏：点右侧风险，左侧原文高亮跳转。进入“团队案件”领取案件，必要时改派。

## 3:20–4:10 翻译 / 导出 / OA

1. 翻译为英语 → 导出**双语对照稿**（段落后插译文）  
2. 采纳若干风险 → 导出**修订建议稿**与**原文版**  
3. 「推送到 OA」→ 信用审核专员/财务审批主管/集团财务总监（最终审批人）角色决策 → 批量更新建议（Mock）
4. 案件附件 Tab 切换查阅

## 4:10–4:40 审计与定制对照

团队管理查看审计；可翻 `docs/enterprise-customization.md` 对照命题 6 条定制项。

## 话术备忘

- 规则候选：16 条封闭底限用确定性词法门控，不依赖向量库。  
- 信审 AI：同学模块；合同侧已强制绑定与越界阻断。
