## 重新导出

PPT 修改后运行:

```
node export.cjs
```

依赖已就地安装（gifenc + pngjs），`node_modules`、`package.json`、`package-lock.json` 可随时删除，不影响导出的图片。

> 注：隐藏了演示器自带的右侧圆点导航与页码角标，只保留幻灯片本体。
