# 合同审查验收基线

本文件定义合同/采购订单自身的底线规则；合同发起前还必须绑定一份已生效客户信审版本。信审决定客户级账期、预付款、额度、付款方式和交付模式，合同不能以本基线或合同例外审批覆盖该决定。

## 规则范围

唯一业务规则源为 `数据包-合同评审/3）合同底线条款/销售合同底限条款.xlsx` 的 16 条销售合同底线。每次审查报告必须记录实际使用的规则版本。

## 样例回归

| 样例 | 必须覆盖的风险方向 | 摄取验收 |
| --- | --- | --- |
| 销售合同例 1 | VMI/JIT、订单取消、间接损失、关联责任、违约赔偿 | 正文条款可定位；后续人工复核规则命中 |
| 销售合同例 2 | 订单取消、质保、连带责任、违约赔偿、价格条款 | 表格和正文均可定位 |
| 销售合同例 3 | 多语言合同中的知识产权、法律识别、质保 | 英文条款不丢失并可进入语义审查 |
| 销售订单例 1 | 间接损失、知识产权、订单责任 | 表格条款必须被解析，且定位到表格行 |

## 判定约束

- 数值、日期、比例、金额类结论必须展示提取事实及规则计算结果。
- 需要 CEO 或总监例外审批的规则，未见有效审批材料时不得判定为可直接签署。
- 任何信审越界（`CREDIT_*`）均为不可在合同端处置的阻断项。放宽商业条件时，必须先完成新的信审审批并基于该版本重新复审合同。
- 无法确认主体、附件优先级、审批材料或金额口径时，进入“待人工确认/待补材料”，不得输出为“通过”。
- 风险报告必须提供原文证据和稳定来源锚点；PDF 使用页码，DOCX 使用正文段落或表格行定位。
